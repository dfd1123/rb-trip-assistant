# 와니의 결재 도우미

아마란스10에서 **출장신청서**와 **출장보고서**를 대신 작성해 주는 데스크톱 앱입니다 (Windows · macOS · Ubuntu).
품의서입력(복수) → 결재상신 → 본문 작성 → **보관(임시저장)** 까지 자동으로 하고, **상신은 사람이 확인한 뒤 직접** 누릅니다.

---

## 팀원용: 설치와 사용

### 설치
| OS | 파일 | 처음 실행할 때 |
|---|---|---|
| Windows | `trip-assistant-x.y.z-win-x64.exe` | "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** |
| macOS | `trip-assistant-x.y.z-mac-arm64.dmg` (Intel 맥은 `x64`) | 앱을 **우클릭 → 열기**. "손상되었다"고 나오면 터미널에서 `xattr -dr com.apple.quarantine "/Applications/와니의 결재 도우미.app"` |
| Ubuntu | `.deb` (`sudo apt install ./파일.deb`) 또는 `.AppImage` (실행 권한 주고 더블클릭) | — |

> 회사 코드서명 인증서가 없어서 첫 실행 경고가 나옵니다. 인증서를 붙이면 사라집니다.
> 설치 파일은 [Releases](https://github.com/dfd1123/rb-trip-assistant/releases/latest) 에서 받습니다. 이후 새 버전은 앱이 알려줍니다.

### 처음 한 번
1. **설정** 탭에서 이름, 예산 부서(기본: 매니퓰레이터 사업부), 기본 출발지(기본: 세종특별자치시 집현동 1095)를 저장
2. **그룹웨어 로그인 확인**을 누르면 앱 안에 아마란스 창이 열립니다. 거기서 평소처럼 로그인하면 이후에는 로그인 상태가 유지됩니다.
   비밀번호는 앱이 저장하지 않고, 로그인 쿠키는 이 PC의 앱 데이터 폴더에만 남습니다.

### 출장 신청 — 한 줄이면 끝
맨 위 칸에 한 줄만 쓰고 **[자동 작성]** (Ctrl/⌘+Enter):

> 다음주 화 저녁에 출발 목 3시 복귀 판교 RBY1 Muscat 연동 검증, 자차, 홍길동이랑 같이

| 자동으로 채우는 것 | 방법 |
|---|---|
| 날짜·시각 | "다음주 화~목", "10/20~22", "11월 3일부터 2박3일", "저녁에 출발", "3시 복귀" 등 |
| 출장지 | 자주 가는 곳(판교 등, 신청할수록 늘어남)과 연구소·사무소·전시장 이름 |
| 교통편·동행자 | 자차/KTX/대중교통/법인차(차량명), "○○이랑 같이" |
| 사유·출장목적 | AI 키가 있으면 AI가, 없으면 템플릿으로 작성 |
| 숙박비 | 1박 70,000원 × (일수 − 1)박 |
| 식대 | 아침 8,000 · 점심 15,000 · 저녁 15,000. **첫날은 출발 시각이 끼니 시작 전이면, 마지막 날은 복귀 시각이 끼니 끝난 뒤면** 포함 (끼니 시간대: 아침 07~08, 점심 12~13, 저녁 18~19). 화면에 날짜별 끼니 내역이 나옵니다 |
| 교통비 | 네이버 지도 왕복: 자차 (연료비 + 통행료) × 2, 대중교통 버스 포함 총 요금 × 2. 같은 경로는 30일간 다시 조회하지 않음 |
| 제목 | `[출장신청 및 출장경비 사전품의] {사유}로 인한 출장의 건` ('로/으로' 자동) |

- 확인이 필요한 칸은 주황색으로 표시됩니다. 내용을 보고 **[그룹웨어에 입력하기]**.
- 같은 곳에 또 가면 **내 출장 → [다시 신청]** 후 날짜만 고르면 됩니다.
- 진행 중 자동으로 못 한 부분은 어디를 손으로 하면 되는지 알려주고 [계속]을 기다립니다.
- 단가·끼니 시간대는 **설정 → 출장비 규정**에서 바꿀 수 있습니다.

### AI 키 (선택)
설정 → AI 문장 작성에서 Claude / OpenAI / Gemini 중 하나와 개인 API 키를 넣으면 사유·출장목적·보고서 문장이 자연스러워집니다.
키는 OS 보안 저장소로 암호화돼 이 PC에만 저장됩니다. 금액은 AI가 아니라 항상 규정으로 계산합니다. 키가 없거나 AI 호출이 실패하면 템플릿으로 작성합니다.

### 출장 보고
- **내 출장 · 보고서** 탭 → [보고서 작성]: 신청 내용, 날짜별 일정, 신청 경비, 출장일시(시각 포함)가 미리 채워져 있습니다.
- 맨 위 칸에 한 일을 대충 적고 **[자동 작성]** → 보고사항과 일정 채움. 실제 금액이 다른 경비만 고친 뒤 [그룹웨어에 입력하기]
- 제목: `[출장보고서 및 정산 품의서] {사유}로 인한 출장 보고의 건`, 교통비 캡처가 자동 첨부됩니다.

## 개발자용

```bash
yarn install
yarn start                 # 앱 실행 (또는 dev.command 더블클릭)
yarn test                  # 규칙 단위 테스트 (조사, 제목, 금액, 검증, AI 답변 파싱)
yarn e2e                   # 가짜 아마란스로 신청서·보고서 전체 흐름 (Linux CI: xvfb-run -a ... --no-sandbox)
yarn electron-builder --mac|--win|--linux --publish never
```

### 배포와 자동 업데이트
1. `package.json` 의 `version` 을 올리고 커밋
2. `git tag v0.3.0 && git push origin main --tags`
3. GitHub Actions: 테스트 → Release 생성 → Windows/macOS/Linux 빌드가 Release 에 업로드 (태그와 package.json 버전이 다르면 실패)

설치된 앱은 시작할 때와 6시간마다 [Releases](https://github.com/dfd1123/rb-trip-assistant/releases) 를 확인합니다.
- **Windows · AppImage**: 백그라운드로 받아두고 상단 알림의 [지금 재시작]으로 적용
- **macOS · deb**: 코드서명이 없어 자동 설치가 막혀 있어서 [다운로드] 알림 → 새 버전을 설치 (Apple 개발자 인증서를 붙이면 macOS 도 자동 설치 가능)

자동 업데이트가 GitHub Releases 에서 파일을 받기 때문에 저장소는 Public 이어야 합니다. 실제 결재 문서 데이터는 저장소에 넣지 마세요.

### 구조
```
src/main.js              창 관리, 화면 API, 작업(사람 확인 포함) 관리
src/renderer/            화면 (index.html, app.js)
src/engine/rules.js      회사 규칙: 제목/조사, 예산과목 코드, 교통비 계산, 입력 검증, AI 프롬프트
src/engine/quick.js      한 줄 메모 해석(날짜·시각·장소·교통편·동행자), 숙박·식대 규정 계산, 템플릿 문장
src/engine/ai.js         개인 API 키로 문장 작성 (Claude/OpenAI/Gemini)
src/engine/gw.js         아마란스 조작: 품의서입력(복수) 그리드 → 결재상신 모달 → 작성 팝업 → 보관
src/engine/editorFill.js 작성 팝업 본문(dzEditor iframe) 채우기 — 라벨 셀 기준, 체크박스는 뒤 글자 기준
src/engine/naver.js      네이버 지도 교통비 조회
src/engine/driver.js     Electron 창 조작 (실제 마우스/키 입력 이벤트, insertText)
test/mock-gw/            실제 화면 구조를 재현한 가짜 아마란스 (RealGrid2 클래스, 코드도움, 결재상신, 팝업)
```

### 아마란스 화면에서 확인한 사실
- 품의서입력(복수): `#/HP/NPC1023/NCA0018`. 그리드는 RealGrid2 DOM (`tr.rg-data-row`, `td.rg-data-cell`, `td.rg-checkbar-cell`, `.rg-list-editor`)
- 품의구분 '지출' 선택 후 Enter 3번 → 예산 라인 행 생성. 부서 칸 → `사업코드도움`, 예산과목 칸 → 코드 검색
- 적요 Enter → 첨부파일, 다시 Enter → 다음 예산 라인. 품의 행 체크 → 하단 [결재상신]
- 전자결재상신 모달: 결재양식 + 제목 → 확인 → `window.open` 작성 팝업. 본문은 `iframe#editorView_*` 안의 표, 제목은 `.docTitleBox input`, 상단 `.topBtn` 미리보기/보관/상신
- 내부 API 는 요청마다 브라우저 서명(`wehago-sign`)이 붙어 직접 호출이 어려움 → 화면 조작 방식. `/oauth/*` 경로는 존재하지만(502) 어떤 Open API 인지 미확인 — 확인되면 `gw.js` 를 API 호출로 바꾸면 됨

### 아직 실제 아마란스에서 확인 못 한 부분 (첫 실행 때 점검)
- 예산과목 코드도움 창의 정확한 제목, 결재양식 드롭다운 동작 → 실패하면 앱이 "도움 필요"로 알려주고 기다림
- 네이버 지도 금액 자동 읽기 → 실패하면 지도 창에서 직접 검색 / 금액 입력
- 출장보고서 본문 HTML (완료 문서 텍스트로 만든 근사치로 테스트함) → 보고서 양식의 [HTML보기] 소스를 `test/fixtures/report_form_body.html` 로 넣고 E2E 재실행 권장
